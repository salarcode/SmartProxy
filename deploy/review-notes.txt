Build instructions (the full source code is attached):

Requirements: Node.js 24 or later, npm.

1. npm install
2. npm run build-ff
3. The extension is created in the "build" folder, this is what is submitted.

Other targets: npm run build-ff-android (Android), npm run build-th (Thunderbird).
Tests: npm test

Third-party libraries are included unmodified as minified files in src/ui/js, src/ui/css and src/pako.min.js:

Bootstrap v5.1.3 and Bootswatch (Cosmo, Flatly) v5.1.3
https://github.com/twbs/bootstrap/releases/download/v5.1.3/bootstrap-5.1.3-dist.zip
https://bootswatch.com/5/cosmo/bootstrap.min.css
https://bootswatch.com/5/flatly/bootstrap.min.css

DataTables 1.11.3 (with RowReorder 1.3.1)
